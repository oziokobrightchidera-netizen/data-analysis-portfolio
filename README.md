# 📊 Excel Business Performance Dashboard

## Project Overview

This project presents an interactive **Business Performance Dashboard** developed using Microsoft Excel to analyze and visualize business performance across different regions.

The dashboard provides insights into revenue, profit trends, regional performance, and product analysis, helping users understand business performance through visual representations of data.

## 🎯 Project Objectives

- Analyze business revenue and profit performance.
- Track revenue and profit trends over time.
- Compare business performance across different regions.
- Present business data using interactive Excel dashboards.
- Support data-driven business decision-making.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Visualization
- Data Analysis

## 📈 Dashboard Features

### 1. Regional Analysis
Analyzes business performance across four regions:

- East
- North
- South
- West

### 2. Profit & Revenue Trend
Visualizes changes in revenue and profit over time using a line chart.

### 3. Regional Profit & Revenue Comparison
Compares revenue and profit across different geographical regions using a column chart.

### 4. Interactive Regional Filter
Allows users to filter dashboard information by selecting individual regions.

### 5. Product Analysis
Provides a dedicated section for examining product-related business performance.

## 💡 Business Questions

This dashboard is designed to help answer questions such as:

1. How does revenue change over time?
2. How does profit change over time?
3. Which region generates the highest revenue?
4. Which region generates the highest profit?
5. How can regional business performance be compared?
6. Which products contribute most to business performance?
